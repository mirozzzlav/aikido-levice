# PHPMailer 7.1.1

Unmodified files from the official [v7.1.1 release](https://github.com/PHPMailer/PHPMailer/releases/tag/v7.1.1).

This minimal distribution includes `src/Exception.php`, `src/PHPMailer.php`,
and `src/SMTP.php` for the contact form's SMTP transport. The classes are loaded
directly by `send.php`, following the upstream
[installation instructions](https://github.com/PHPMailer/PHPMailer#installation--loading).

The upstream license and cooperation commitment are included as `LICENSE`
and `COMMITMENT`. Keep these files when updating the library.
